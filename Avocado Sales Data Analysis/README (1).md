## Project Overview

This project analyzes **Avocado Sales Data from 2015 to 2023** to uncover trends in sales volume, pricing, and regional demand.

Using **Microsoft Excel**, the raw dataset was transformed into **structured summaries, analytical tables, and a visual dashboard** that helps stakeholders understand market performance.

The project demonstrates practical **data analysis skills commonly required in analyst roles**, including:

- Data cleaning
- Aggregation
- Pivot table analysis
- Dashboard building
- Business insight generation

---

# Business Questions

This analysis answers key business questions:

- Which **regions generate the highest avocado sales volume?**
- How do **organic and conventional avocados compare in demand and revenue?**
- What **pricing patterns** exist across the market?
- Are there **seasonal trends in avocado consumption?**

---

# Dataset Information

**Source:** Avocado retail sales dataset

**Total Records:** 53,415

### Key Variables

| Column | Description |
|------|-------------|
| Type | Conventional or Organic avocado |
| Region | Sales region |
| Total Volume | Total avocado sales volume |
| Price | Average selling price |
| Total Bags | Total bags sold |
| Small Bags | Small bag sales |
| Large Bags | Large bag sales |
| Extra Large Bags | XL bag sales |
| Revenue | Total revenue generated |

# Key Insights

Key findings from the analysis:

- Conventional avocados account for the **largest share of total sales volume**
- Organic avocados typically command **higher market prices**
- Certain regions dominate national sales
- Demand patterns fluctuate seasonally
